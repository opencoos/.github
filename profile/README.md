<h1 align="center">OpenCOOS</h1>

<p align="center"><strong>Open standards for community management</strong><br>
🍁 Proudly Canadian · For strata and condo communities across Canada</p>

---

OpenCOOS maintains **COOS — the Common Ownership Operating Schema**: an open, vendor-neutral data model for shared-ownership communities. It gives strata corporations in British Columbia and condominium corporations in Ontario, Alberta and across Canada a common language, so software platforms, property managers and councils and boards can exchange information consistently.

> **Status: early development.** Version `0.1.0-draft` is an unreleased working draft, modelled first on BC strata. Ontario and Alberta condominiums are the next priority. Nothing is stable yet, so this is the best time to shape it.

### Get involved

You don't need to be a developer. Strata council members, condo board directors, owners, property managers, lawyers, accountants, engineers and software vendors can all help.

- **Spot a problem or a term that doesn't match your province?** [Open an issue](https://github.com/opencoos/spec/issues/new/choose)
- **Want to propose a change?** Read the [contribution guide](https://github.com/opencoos/.github/blob/main/CONTRIBUTING.md)
